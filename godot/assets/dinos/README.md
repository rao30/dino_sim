# Quaternius Animated Dinosaur Pack (CC0)

Source: https://quaternius.com/packs/animateddinosaurs.html
Also: https://quaternius.itch.io/animated-lowpoly-dinosaurs

Original formats: FBX / Blend / OBJ (Dec 2018).
These `.glb` files were rebaked from the FBX with visual keying (IK cleared)
via `scripts/bake_quaternius_glb.py` for Godot 4.6 skeletal playback.
